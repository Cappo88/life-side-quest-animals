# 🐾 我的支线任务：遇见猫咪

> 今天，你遇到猫了吗？

拍照上传遇到的猫咪，生成词条，补上它的性格和声音，收进属于你自己的猫咪图鉴。

## ✨ 功能

- 📸 **拍照 / 上传**：随手记录遇见的猫咪
- 💫 **飘动词条**：词条以浮现 + 呼吸感动画展示
- 📝 **补充信息**：为猫咪添加性格标签和声音标签
- 📖 **猫咪图鉴**：所有记录保存在本地，形成你的遇见档案

## 🚀 本地运行

不需要构建工具，直接双击 `index.html` 即可在浏览器打开。

## 🧠 关于识别

本项目的识别流程参考了以下 MIT 许可的开源项目：

- **猫检测**（Flutter/TFLite）：多阶段管线思路
- **动物检测**（Flutter/TFLite）：可配置的检测阈值
- **MeowIDAPI**（PyTorch/Flask）：API 设计参考
- **狗_猫_品种_分类**：品种列表参考

**当前版本**：颜色分析是真实读取图片像素并聚类主色的。品种匹配在本地进行。

**接入真实 AI 识别**：打开 `app.js`，修改顶部配置：

```js
const CONFIG = {
  使用真实API: true,
  apiURL: 'https://your-server.com/pridictBreed',
  apiKey: ''
};
```

> ⚠️ **安全提醒**：不要把 API Key 硬编码在前端。
